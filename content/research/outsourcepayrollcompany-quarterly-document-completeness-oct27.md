Published October 27, 2026.

This protocol measures the document request process, not the accuracy of a tax return. It tracks whether each requested item arrived with the right period, entity, pages, and version before the reviewer saw it.

## Research question and decision use

The question is how often a quarterly document set is complete and timely at first receipt, and which checks fail most often. Operations leaders can use it to improve request templates and provider follow-up. It should not be used to judge the tax treatment of a return.

## Population and eligibility

Include every document request opened for the quarter that names a return, schedule, or supporting report. Record the filing calendar, the request date, the internal due date, and the owner. Exclude requests for prior-quarter corrections and report them separately.

## Completeness checks

Define five checks: correct quarter, correct legal entity or account, required page count, readable totals, and current version. A document passes only when all five are present. Record partial passes with the specific missing check rather than a single complete flag.

## Timing measures

Measure the interval from request to first receipt and from first receipt to reviewer acceptance. Record whether the first receipt met the internal due date. Keep late receipts in the population and note whether a follow-up was required.

## Analysis plan

Report first-pass completeness by document type, the share requiring a second version, and the median receipt interval. Use the number of requests as the denominator and show the count behind every rate. Compare quarters with the same request list and check definitions.

## Exception and sensitivity review

List cases where a document was accepted despite a missing check, and the owner who accepted it. Test whether the conclusion changes when those exceptions are excluded. A provider outage or a new filing requirement should be described, not averaged away.

## Privacy and limitations

Keep tax documents in restricted storage and report only aggregate results. The study observes the request and receipt record and cannot determine whether a filed return was correct. Late mail, portal changes, and staffing shifts may affect completeness.

## Replication package

Retain the request list, filing calendar, receipt timestamps, completeness classifications, reviewer acceptance notes, and calculations. A later cycle should use the same five checks or disclose the change before comparing results.
